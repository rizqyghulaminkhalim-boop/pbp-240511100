# Analisis Komparatif Platform Web, Desktop, dan Mobile

## Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | C#, Java, C++, Python | Kotlin, Java, Swift |
| Arsitektur | Client-server | Berjalan pada sistem operasi komputer | Berjalan pada sistem operasi perangkat mobile |
| Cara distribusi | Melalui browser dan server web | Installer atau toko aplikasi | Play Store, App Store, atau distribusi lainnya |
| Keunggulan | Mudah diakses melalui browser | Dapat memanfaatkan sumber daya komputer | Praktis dan mendukung fitur perangkat seperti GPS dan kamera |
| Keterbatasan | Beberapa fitur bergantung pada browser dan koneksi jaringan | Perlu menyesuaikan sistem operasi | Memiliki keterbatasan baterai dan ukuran layar |
| Contoh aplikasi | Gmail, Google Docs | Visual Studio Code, Microsoft Word | WhatsApp, Google Maps |

## Kesimpulan

Platform Web, Desktop, dan Mobile mempunyai karakteristik yang berbeda. Web cocok untuk aplikasi yang membutuhkan akses melalui browser, Desktop sesuai untuk aplikasi yang memerlukan integrasi dengan sistem operasi komputer, sedangkan Mobile cocok untuk aplikasi yang digunakan melalui perangkat bergerak. Pemilihan platform perlu mempertimbangkan kebutuhan pengguna, fitur aplikasi, dan kemudahan pengembangan.
